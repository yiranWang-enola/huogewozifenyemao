| 问题类别 | 问题名称 | 发生原因 | 解决办法 |
| :--- | :--- | :--- | :--- |
| 项目运行与部署 | 无法正确启动 Django 开发服务器，或启动后无法访问对应页面 | 环境配置的解释器发生版本冲突 | 降低个别配置的版本，达到兼容 |
| 前后端对接 | 算法无法正确接入前端 | 传入参数不匹配，未将返回值转换成 Json 格式 | 找到接收参数和调用参数的函数，统一返回格式 |
| 算法准确度 | 选择“偏好计算机”却推荐工商管理专业 | 各项权值计算逻辑错误，导致结果有偏差 | 重新梳理算法逻辑进行优化 |
| 数据层异常与权重失衡 | 专业推荐指数显示不出来，或数据差距太大 | 过滤条件过严，标签不匹配导致无推荐专业，权重分配失衡个别因素占比过小 | 在算法中加入相似平衡限制条件，异常值截断，优化算法逻辑 |
| 前后端协调 | 维度得分分布在图像中的显示占总值过小，影响页面美观，不方便用户理解 | 前端页面布局与后端传值不匹配，未对数据进行归一化 | 在视图代码中添加对应归一化处理并美化页面 |
